# Viacao-Calango
*Api de Trabalho de faculdade*
O Sr. Water Falls, satisfeito com o ultimo trabalho executado pela XptoTec solicitou um novo sistema para
controlar sua empresa de transporte interestadual. Os ônibus da viação Calango possuem 23, 28 ou 32
lugares. Há ônibus leito, semi-leito e executivo. As diversas rotas definem os locais onde os passageiros
podem comprar as passagens. As passagens são vendidas para qualquer trecho e em todas as paradas é
possível embarcar e desembarcar. As passagens compradas para todo o percurso da rota tem preço
promocional, bem como as passagens compradas com antecedência. Nesta última modalidade o valor
varia de acordo com critérios de tempo de antecedência, que deve ser parametrizável. As passagens
possuem também diferentes preços para cada tipo de ônibus.
O ônibus é conduzido por um motorista que não pode dirigir mais de 6 horas ou mais de 400km, onde é
preciso trocar de motorista que esteja sem dirigir por 12 horas. Os motoristas são trocados nas paradas
de troca previamente conhecidas. O sistema deverá alocar os motoristas nos ônibus de acordo com esta
regra e deverá ter sempre motorista disponível.
O sistema deverá alocar os passageiros conforme a quantidade de passagens vendidas para cada rota,
vendo a alocação ideal de forma que haja o mínimo de espaços vazios nos ônibus.
Todo ônibus deve passar por uma revisão a cada 10.000 km, o sistema deve controlar a quilometragem
dos ônibus para que seja encaminhado para revisão quando completar os 10.000 sem revisão.
Os pagamentos das passagens podem ser feitos via internet por cartão, ou em dinheiro nos guichês da
companhia nas rodoviárias espalhadas pelo Brasil. O sistema poderá ser usado via internet pelos
passageiros ou por funcionários nos guichês.
